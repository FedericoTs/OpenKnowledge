**No product code changed since v0.12.4.** `git diff v0.12.4..v0.12.5 -- src/` is
empty: this installer is the previous one with a different number on it. What
changed is what this project claims, and the claims got worse.

**Accuracy, measured for the first time on documents nobody here wrote.** The US
Federal Travel Regulation from eCFR — 20 documents, 205 sections — asked GSA's own
per-diem FAQ, verbatim. GSA writes both the regulation and the FAQ, so neither the
corpus nor the questions came from anyone who built this. Both are committed under
`evals/golden-ftr/`, public domain, so the run is reproducible rather than merely
described.

| | the corpus we wrote | FTR, BM25 only | FTR, the shipped default |
|---|---:|---:|---:|
| accuracy on questions the corpus answers | 100% | 71% (5 of 7) | 57% (4 of 7) |
| false answers on questions it does not | 0 of 9 | 0 of 12 | **1 of 12** |
| cost per question | $0.00000 | $0.00000 | $0.00000 |

**The shipped default is the weaker column.** Adding embeddings to BM25 lost two
correct answers and produced the first false answer this system has given in any
evaluation here: asked whether hotels can refuse the federal per diem rate — which
these chapters do not address — it said they cannot. GSA's FAQ says they are not
required to honour it, so the answer was unsupported by the corpus and wrong about
the world. Setting `OK_EMBEDDING_ENABLED=false` gives the middle column.

**Two failures are open and unfixed, and both reproduced on a cold cache.** The
first-and-last-day M&IE rate is refused on one of two identical asks and answered
correctly, with a citation, on the other — the grounding gate rejecting a correct
and well-supported answer about half the time, which is a determinism break on this
project's headline claim. And the one-day-travel question retrieves the right
document and the wrong chunk, answering from the meal-deduction rule instead of the
one that carries the 75 percent rate. Neither was fixed before the number was
recorded, because fixing them first would have hidden the number.

Three of the first run's failures turned out to be defects in the exam rather than
the product, all the same mistake: a forbidden phrase that a correct answer can
also contain. Both numbers are published — 50% as the exam was first written, 71%
after those corrections — with the reasoning in each case's own notes.
