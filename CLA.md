other terms — commercial licences for organisations whose policy forbids AGPL, and a
commercial edition alongside the free one. That is only possible if copyright stays
consolidated; without this agreement, relicensing would require tracking down every
contributor.

work however you like), and it does not let the maintainer make the existing AGPL release
disappear. Code released under AGPL stays available under AGPL. If that trade is not one you
want to make, please open an issue instead of a pull request — design help, bug reports, and
documentation feedback are valuable and need no agreement.
