How it works

It will not guess, and it can prove what it cost.

Every answer is built only from passages retrieved out of your documents, cites them, and is checked before you ever see it.

Deterministic by construction

The same question returns the same answer — from a cache key over the question, the corpus version, the prompt and the model route. Not from a temperature setting, which cannot deliver it.

A gate before you see it

Invented citations, figures absent from the sources, and ungrounded prose are rejected. The question then goes to a better model if you have configured one, and is refused if you have not — never answered badly.

It refuses when sources disagree

Where two current documents contradict each other, it names both figures and both documents rather than picking the one that sounds more recent.

A ladder, not a cliff

Self-hosted → open-weight → frontier, each answering from the same passages under the same gate. A cheaper rung lowers the bill, never the standard.

A budget that caps escalation

A daily limit becomes a ceiling on what one question may cost, recomputed from the ledger. It limits escalation, never service.

Access control that fails closed

Applied while retrieving, and re-checked before any cached answer is served to somebody who could not have retrieved its sources themselves.

What that is, and is not.

The test corpus and its questions were written together, which is the circularity that makes benchmarks flattering. It shows the pipeline behaves — retrieval finds the evidence, conditions survive, negations do not invert, contradictions refuse. It is not evidence about accuracy on your documents. The golden set is itself checked to be capable of failing: every case is fed its own plausible wrong answer and must reject it.

Honestly

What it does not do yet.

Landing pages leave this out. This one is the reason to believe the rest of the page.

  • No SharePoint or Teams connectorIt reads a local folder today. Microsoft Graph is free to call and its delta queries suit the design, but none of it is built — and the real work there is mapping item permissions, not downloading files.
  • The paid tiers are unmeasuredThe self-hosted tier has been run end to end. The open-weight and frontier rungs have not, so the escalation rate the cost model turns on is still an assumption.
  • Contradiction detection is not ready for a mixed corpusOn 15 real vendor contracts it correctly identified six pairs of duplicated documents — and every one of its six other findings was false. It has no notion of scope: contracts with different counterparties have no business agreeing with each other, and nothing in it knows that. It works on one organisation's own policies.
  • No OCRA scanned PDF is reported as unreadable rather than silently indexed as nothing.
  • English onlyFor the rules that detect a changed permission. Figures are found in any language.
  • A confidence score was built, measured and withdrawnIt rose as retrieval was degraded — 13 of 17 answers grew more confident on less evidence — so it was removed rather than shipped.

Install

One command, then a folder.

Nothing to sign up for. No account, no cloud project, no waiting list.

Install it

Clones the repository, sets up an isolated environment, and checks it works. Nothing is installed system-wide.

curl -fsSL https://raw.githubusercontent.com/FedericoTs/OpenKnowledge/HEAD/install.sh | sh

Prefer to read it first? git clone the repository and run ./install.sh — same result, and the script is 117 lines.

Point it at your documents

Free, offline, and writes nothing. This is the whole audit tier.

openknowledge audit ~/policies

Add a model when you want answers

A model on your own machine costs nothing per question. An open-weight endpoint costs about $0.0003 and reaches the same adapter — configuration, not code.

# on your machine, nothing leaves it
openknowledge model use qwen3:8b

# or a long-context model, for large documents
openknowledge model use qwen3:30b --context 131072

Run it

Chat widget, HTTP API and this page, all from the same container.

openknowledge serve        # http://localhost:8080
