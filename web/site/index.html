Start here

Start with the free half

Before any of the rest, point it at a folder. It reads your documents and tells you where they contradict each other. No API key, no model, no GPU, no database, nothing written, and nothing leaves the machine. 

uv run openknowledge audit ./policies
OpenKnowledge audit - /srv/policies
11 document(s), 151 claim(s) checked, 0 model calls, $0.00

2 contradiction(s), in 2 document pair(s):

  1. expenses-policy vs travel-guidelines   (figure, 43% context match)
     [expenses-policy] says EUR 500
       "Any single item of travel expenditure above EUR 500 requires written approval..."
     [travel-guidelines] says EUR 1,000
       "Travel expenditure above EUR 1,000 requires written approval before booking."

1 pair(s) look like duplicated documents:

     expenses-policy-2023 and expenses-policy look like two versions of the same

     reconciling them line by line.

It exits non-zero on findings, so it also works as a CI step on the repository where your policies live — a pull request that makes two documents disagree fails before anybody is answered from either.

Then, if you want answers

The same corpus becomes a question-answering service that will not guess. Every answer is built only from retrieved passages, cites its sources, and is checked before you see it: invented citations, unsupported figures and ungrounded prose are rejected, and the question escalates to a better model rather than being answered badly.

  • Deterministic. The same question returns the same answer, from a cache key over the question, the corpus version, the prompt and the model route — not from a temperature setting.
  • It refuses. If your documents disagree, it says so and names both figures rather than picking the one that sounds more current.
  • A ladder, not a cliff. Self-hosted → open-weight → frontier, each answering from the same passages under the same gate. Cheaper rungs lower the bill, never the standard.
  • A budget that limits escalation, not service. A daily cap becomes a ceiling on what one question may cost, recomputed from the ledger.
  • Access control that fails closed, applied during retrieval and re-checked before any cached answer is served.

What that is and is not. The test corpus and the questions were written together, which is the circularity that makes benchmarks flattering. It shows the pipeline behaves — retrieval finds the evidence, conditions survive, negations do not invert, contradictions refuse. It is not evidence about accuracy on your documents. The golden set is checked to be capable of failing: every case is fed its own plausible wrong answer and must reject it.

Honestly

What it does not do yet

Landing pages usually leave this out. This one is the reason to trust the rest of the page.

  • No SharePoint or Teams connector. It reads a local folder today. Microsoft Graph is free to call and the design is written against it; the work is mapping item permissions, not downloading files.
  • The paid tiers are unmeasured. The self-hosted tier has been run end to end. The open-weight and frontier rungs have not, so the escalation rate the cost model turns on is still an assumption.
  • Contradiction detection is not ready for a mixed corpus. On 15 real vendor contracts it correctly identified six duplicated documents — and its six other findings were all false. It has no notion of scope: contracts with different counterparties have no business agreeing with each other, and nothing in it knows that. It works on one organisation's own policies.
  • No OCR. A scanned PDF is reported as unreadable rather than silently indexed as nothing.
  • English only for the rules that detect changed permissions.
  • A confidence score was built, measured and withdrawn. It rose as retrieval was degraded — 13 of 17 answers got more confident on less evidence — so it was removed rather than shipped.

Install

Get it

Nothing to sign up for. It is a repository and a container.

Try the audit, no configuration

git clone https://github.com/FedericoTs/OpenKnowledge
cd OpenKnowledge
uv venv && uv pip install -e ".[dev]"
uv run openknowledge audit ./your-policies

Run the whole thing

cp .env.example .env      # optional: add a key for the escalation tier
docker compose up         # chat widget on http://localhost:8080

Point it at a model

# free and private — a model on your own machine
OK_LOCAL_MODEL=qwen3:8b
OK_LOCAL_BASE_URL=http://localhost:11434/v1

# or an open-weight endpoint: same adapter, ~$0.0003 a question
OK_LOCAL_MODEL=openai/gpt-oss-20b
OK_LOCAL_BASE_URL=https://api.together.xyz/v1

Step by step, including a first measured run: TEST-RUN.md. Why it costs what it costs: COST-MODEL.md.
