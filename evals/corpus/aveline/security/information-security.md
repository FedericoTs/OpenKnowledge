# Information Security Policy

**Owner:** Chief Information Security Officer · **Version:** 5.2 · **Effective:** 1 February 2026

## 1. Access

### 1.1 Multi-factor authentication

Multi-factor authentication is **mandatory** on every Aveline system that
supports it, including email, the VPN, the code repositories and the cloud
consoles. SMS is not an acceptable second factor; use the authenticator
application issued by IT or a hardware key.

### 1.2 Passwords

Passwords must be at least **14 characters**. They must not be reused across
Aveline and personal accounts. Passwords are not rotated on a schedule; they are
changed only where there is reason to believe one has been exposed.

### 1.3 Remote access

The VPN must be used for any access to internal systems from outside an Aveline
office. VPN sessions expire after **12 hours** and must be re-authenticated.

## 2. Devices

Laptops must have full-disk encryption enabled. IT verifies this at issue and
monthly thereafter.

Removable USB storage is **prohibited** on Aveline laptops. Where a file must be
moved to an external party, use the approved secure transfer service.

Personal devices may be used for email and calendar only, and only where the
device is enrolled in mobile device management.

## 3. Incidents

### 3.1 Reporting

A suspected security incident must be reported to the security team within
**4 hours** of discovery. This deadline applies to the internal report and is
separate from any regulatory notification obligation.

Reporting is required even where the reporter believes the incident is minor or
turns out to be a false alarm. Nobody has ever been disciplined at Aveline for
reporting an incident that proved to be nothing.

### 3.2 Handling

The security team triages within 2 hours of receiving a report and assigns a
severity. Severity 1 incidents convene the incident response group immediately
and page the Chief Information Security Officer.

## 4. Training

Security awareness training is mandatory annually and must be completed within
30 days of assignment. New joiners must complete it within their first two weeks.
